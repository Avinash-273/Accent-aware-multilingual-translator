# Accent-Aware Multilingual Translator — Streamlit

A Streamlit app for multilingual text translation using OpenRouter, with optional speech playback generated by gTTS.

## Features
- 17 target languages, including Kannada, Telugu, Tamil, Malayalam, Marathi, Urdu, and Bhojpuri.
- Translations are guided to use the target language's native writing system.
- Download translations as UTF-8 text files.
- Generate MP3 speech at normal or slow speed when a gTTS voice is available.
- OpenRouter API key is kept in Streamlit Secrets or the server environment.

## Run locally

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Create `.streamlit/secrets.toml` for local use:

```toml
OPENROUTER_API_KEY = "your_openrouter_api_key"
OPENROUTER_MODEL = "nvidia/nemotron-3-ultra-550b-a55b:free"
```

## Deploy on Streamlit Community Cloud

1. Open https://share.streamlit.io and sign in with GitHub.
2. Create an app from this repository, branch `main`, with `app.py` as the entrypoint.
3. In the app's Settings → Secrets, add:

```toml
OPENROUTER_API_KEY = "your_openrouter_api_key"
OPENROUTER_MODEL = "nvidia/nemotron-3-ultra-550b-a55b:free"
```

4. Save and let Community Cloud install `requirements.txt` and deploy the app.

Never commit `.streamlit/secrets.toml`, `.env`, or API keys. OpenRouter free endpoints are rate-limited and may be temporarily unavailable. Bhojpuri speech currently falls back to a Hindi voice because Bhojpuri is not listed in the gTTS language catalog; the translation text itself remains Bhojpuri.
